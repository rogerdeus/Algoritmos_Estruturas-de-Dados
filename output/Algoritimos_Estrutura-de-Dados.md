# Algoritmos e Estruturas de Dados
 
Repositório com implementações em **C** de algoritmos clássicos e estruturas de dados fundamentais, desenvolvido como material de estudo/prática da disciplina de Estruturas de Dados.
 
## 📂 Conteúdo do repositório
 
| Arquivo | Descrição |
|---|---|
| `vetor.c` | Leitura e impressão de um vetor de 10 posições. |
| `invercao_vetor.c` | Inverte a ordem dos elementos de um vetor de 5 posições. |
| `transposi_vetor.c` | Calcula a transposta de uma matriz 2x3. |
| `listaencadeada_simples.c` | Implementação de lista encadeada simples (inserção, etc.). |
| `listaencadeada_dupla.c` | Implementação de lista duplamente encadeada. |
| `listaencadeada_circular.c` | Implementação de lista circular com encadeamento simples. |
| `fila.c` | Implementação de fila (FIFO) usando lista encadeada. |
| `multi.c` | Arquivo reservado (ainda vazio/sem conteúdo). |
| `output/` | Pasta reservada para arquivos de saída/binários compilados. |
 
## 🧠 Tópicos abordados
 
- **Vetores e matrizes**: leitura, impressão, inversão e transposição.
- **Listas encadeadas**: simples, duplas e circulares.
- **Filas (FIFO)**: estrutura baseada em nós encadeados.
## 🚀 Como compilar e executar
 
Todos os programas são escritos em C e podem ser compilados individualmente com o `gcc`:
 
```bash
gcc nome_do_arquivo.c -o programa
./programa
```
 
Exemplo:
 
```bash
gcc vetor.c -o vetor
./vetor
```
 
## 🛠️ Requisitos
 
- Compilador C (GCC, Clang ou similar)
- Sistema Linux, macOS ou Windows (com MinGW/WSL)
